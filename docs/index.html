Liquid Glass,
tuned by you

On macOS 26 and later, Whisk can render its panel as real Liquid Glass. The selection stretches and settles like a drop of water as you move from window to window.

  • Clear ↔ Frosted slider to choose how see-through the glass is.
  • Smooth at 120 fps on ProMotion displays.
  • One switch to go back to the classic design any time.

Install in a minute

Whisk is not notarized by Apple (that needs a paid developer account), so macOS asks you to confirm the first launch.

Download

Get the latest .dmg from the Releases page and drag Whisk to Applications.

Open it once

Right-click Whisk → Open → Open. Or run the command below in Terminal.

Grant two permissions

Accessibility (to detect the shortcut and raise windows) and Screen Recording (for previews).

xattr -dr com.apple.quarantine /Applications/Whisk.app

Prefer building it yourself? git clone https://github.com/nithinkr080/Whisk.git && cd Whisk && ./build.sh

Questions

The short answers.

Is Whisk really free?

Yes. It is MIT licensed and open source. Every feature is included: there is no paid tier, trial or subscription.

Why does macOS say it can't be opened?

Notarizing an app with Apple costs $99 a year, so Whisk is only signed ad hoc. Right-click → Open once, or run the xattr command above. You can also read and build the source yourself.

Why does it need Accessibility and Screen Recording?

Accessibility lets Whisk detect your shortcut and raise, close or minimize windows. Screen Recording lets it draw previews of your windows. Previews are kept in memory only, and Whisk never connects to the internet.

Does it work with fullscreen apps and multiple Spaces?

Yes, that is a core feature. Choosing a window in a fullscreen app or on another desktop takes you to its Space.

Which Macs and macOS versions are supported?

macOS 14 or later, on Apple Silicon and Intel. The Liquid Glass design needs macOS 26 or later; older versions get a frosted fallback.

Why can't it be on the Mac App Store?

To reach windows on other Spaces, Whisk uses a few private macOS APIs, as other window switchers do. Apple does not allow that in the App Store, and a future macOS update could affect parts of it.

Is it related to AltTab?

No. Whisk is inspired by AltTab and similar switchers, but it is an independent project written from scratch and is not affiliated with or endorsed by AltTab.
